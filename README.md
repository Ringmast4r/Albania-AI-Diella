## `> the_iranian_cyberwar`

**Context:** Iran retaliated for Albania hosting the MEK (Iranian opposition) by systematically destroying Albanian government systems (2022-2024). The same agency that built Diella (AKSHI) was **directly compromised** by Iranian state hackers.

### Attack Timeline

| Date | Event |
|------|-------|
| **May 2021** | Initial access gained via CVE-2019-0604 (SharePoint) — 14 months of dormancy |
| **July 18, 2022** | Albania shuts down government services as attack begins |
| **July 21, 2022** | HomeLand Justice (Iranian hackers) claims responsibility, begins data leaks |
| **Sept 2022** | Albania severs diplomatic ties with Iran; police database leaked (100k records) |
| **Dec 2023** | Parliament + telecom attacked; claims 2 petabytes deleted |
| **Jan 2024** | INSTAT (statistics) breached; claims 100+ terabytes exfiltrated |

### What Was Leaked

**Police Database (1.7 GB):**
- ~100,000 suspect records
- Photographs, ID numbers, full names, dates of birth, birthplace, nationality

**Government Officials:**
- Police Chief: 47 pages of personal info + border crossing records
- Interior Minister: Email mailbox
- Defense Minister: Email mailbox
- Prime Minister Edi Rama: Correspondence with citizens
- SHISH (Intelligence Agency): Employee names, emails, phone numbers

**Citizen Data:**
- Name, surname, birthplace, phone number, ID card number (mass leak)
- 910,000 voter records (April 2021)
- 637,138 salary records (Dec 2021) — **22% of Albania's entire population**

### Still Active

## `> how_we_found_it`

### All Sources Were Public and Unauth

**1. Albanian Parliament (Kuvendi)**

The parliament published their entire document archive via Azure blob storage with a complete, unauthenticated JSON index:

```
API Endpoint: https://api.kuvendi.al/api/dokumentet
Response: Array of 30,000+ documents with direct blob URLs
Blob Store: kuvendiwebfiles.blob.core.windows.net/webfiles/
Authentication: None required
```

Every document has a direct, public URL:
```
https://kuvendiwebfiles.blob.core.windows.net/webfiles/20190117115944rezoluta%20e%20AK-se%20dt%20%203%205%202018.pdf
```

`opendata.gov.al` publishes government datasets via EU-DCAT standard:
```
Format: JSON + CSV
```

## `> key_findings`

### 1. AKSHI Leadership Corruption

The agency responsible for Albania's digital transformation was led by officials arrested for tender manipulation and corruption — exactly what Diella was supposed to prevent.

**Impact:** Questions trust in Diella's independence, data security, and oversight.

### 2. Iranian Cyber Compromise (Still Unresolved)

AKSHI was directly breached by Iranian state hackers in 2022 using ROADSWEEP/ZeroCleare malware. The compromise lasted **14 months before detection**.

**Impact:** Data integrity of Diella's training data cannot be verified.

### 3. Mass Citizen Data Leaks

1.5+ million Albanian citizens' personal data exposed across multiple breaches:
- 910k voter records (2021)
- 637k salary records (2021)
- 100k police suspect database (2022)

**Impact:** Citizens have legitimate privacy concerns about trusting Diella with additional data.

### 4. All Data Sources Are Public

30,000+ parliamentary documents and government datasets were published via open, unauthenticated APIs. No systems were hacked; the government published everything openly.

**Impact:** This archive represents what is *officially available* — not leaked or stolen.
